Редактор поля

Включи редактор, выбери цвет и фигуру, затем нажимай на любые клетки. В режиме игры фигуры ходят по очереди.

Способности

Выбери способность, затем нажми на свою фигуру, чтобы назначить её. Способность сработает после хода этой фигуры.
