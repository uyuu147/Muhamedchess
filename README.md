# muhamedchess

Android-приложение для шахматной партии двух игроков на одном телефоне. Интерфейс на русском языке, премиальная тёмная тема.

## Возможности

- Полные правила шахмат благодаря библиотеке `chess.js`: легальные ходы, шах, мат, пат, рокировка, взятие на проходе и превращение пешки.
- Два игрока по очереди используют одно устройство.
- Подсветка выбранной фигуры и доступных ходов.
- Отмена последнего хода, переворот доски, новая партия.
- История ходов в алгебраической нотации.
- Нет аккаунтов, сервера и сетевого режима.

## Требования

- Компьютер с Windows, macOS или Linux.
- Node.js LTS (рекомендуется 20.x).
- Android-телефон с включённой отладкой по USB для запуска через ADB, либо приложение Expo Go для быстрого предпросмотра.
- Для создания APK в облаке — аккаунт Expo и EAS CLI.

## 1. Установка зависимостей

Распакуйте архив, откройте терминал в папке `muhamedchess` и выполните:

```bash
npm install
```

## 2. Запуск на телефоне через Expo Go

1. Установите Expo Go из Google Play на Android.
2. На компьютере в папке проекта выполните:

```bash
npx expo start
```

3. Компьютер и телефон должны быть в одной Wi-Fi сети.
4. Отсканируйте QR-код камерой/Expo Go.
5. Приложение откроется на телефоне.

Если локальная сеть блокирует подключение, попробуйте:

```bash
npx expo start --tunnel
```

## 3. Сборка APK для Android

Самый простой способ — облачная сборка Expo EAS.

Установите EAS CLI:

```bash
npm install -g eas-cli
```

Войдите в аккаунт Expo:

```bash
eas login
```

Настройте проект:

```bash
eas build:configure
```

Соберите устанавливаемый APK:

```bash
eas build --platform android --profile preview
```

После завершения EAS покажет ссылку на APK. Откройте её на Android-телефоне и установите файл. При первой установке Android может попросить разрешить установку приложений из этого источника.

## 4. Сборка для Google Play

Для публикации в Google Play используется Android App Bundle:

```bash
eas build --platform android --profile production
```

Результат — `.aab`. Для публикации потребуется аккаунт Google Play Console, оформление страницы приложения, политика конфиденциальности (если применимо) и прохождение требований Google Play.

## 5. Проверка и публикация обновлений

В приложении добавлена кнопка **«Проверить»**. Она проверяет канал Expo EAS Update, загружает доступное обновление и предлагает перезапустить приложение. Это подходит для изменений JavaScript/интерфейса. Изменения нативных модулей, разрешений или Android-конфигурации требуют новой APK-сборки.

### Однократная настройка (разработчиком)

1. Установите зависимости: `npm install`.
2. Выполните `npx eas-cli@latest login` и `npx eas-cli@latest init`.
3. Команда `eas init` создаст проект и присвоит ему ID. Замените `REPLACE_WITH_EAS_PROJECT_ID` в `app.json` на этот ID **в обоих местах**: `updates.url` и `extra.eas.projectId`.
4. Установите конфигурацию обновлений: `npx expo install expo-updates`.
5. Соберите и установите новую APK, чтобы пользователи получили встроенную поддержку обновлений:

```bash
npx eas-cli@latest build --platform android --profile preview
```

### Выпуск обычного обновления приложения

После изменения `App.tsx` или других JS/TS-файлов выполните:

```bash
npx eas-cli@latest update --channel preview --message "Описание изменений"
```

Установленная APK проверит обновление при запуске и также позволит проверить его вручную кнопкой в приложении. Для обновлений production используйте канал `production` и публикуйте релиз в этот канал.

**Важно:** обновления OTA не заменяют новую APK, если меняются нативные зависимости или настройки Android. Для таких изменений увеличивайте `version` и `android.versionCode` в `app.json`, собирайте новую APK/AAB и распространяйте её тем же способом, которым установлено приложение.

## Структура

```text
muhamedchess/
├── App.tsx       # интерфейс, доска и логика взаимодействия

└── README.md     # эта инструкция
```

## Важные замечания

- Идентификатор Android-пакета: `com.muhamedchess.app`. Если он уже занят в Google Play, замените его в `app.json` до публикации.
- Это исходный проект приложения, а не уже собранный и протестированный APK. Для сборки нужен Node.js и запуск команд из инструкции.
- Приложение рассчитано на локальную игру на одном устройстве. Интернет нужен для установки зависимостей и облачной сборки, но не для самой шахматной партии.
